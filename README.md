# 轮腿机器人 - 毕设版

## PS2 操作说明

**注意：手柄信号可能不稳定，存在失控风险**

### 按键功能

- **失能按键**：`R2` (右上角第2个键)
  - 发送电机失能信号
  - 关节电机指示灯变为红色
  - 支持远程停止机器人

- **使能按键**：`start`
  - 发送电机使能信号  
  - 电机指示灯变为绿色

- **启动控制**：`L2` (左上角第二个键)
  - 需在电机使能后使用
  - 启动控制程序

- **跳跃功能**：`R1` (右上角第一个键)

- **前后移动**：右摇杆前后方向

- **左右旋转**：右摇杆左右方向

- **腿长变化**：左摇杆前后方向

- **横滚角控制**：左摇杆左右方向
